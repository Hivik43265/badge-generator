# Этап 12 — Frontend: лента вместо главного окна

Основа — `ui/mockup`, таблица действий — `reports/stage-12-actions.md` (58 действий, 24 дубля удалены).
Backend API v4 (коммит e54a0b6) подключён напрямую, без getattr и заглушек «ожидает Backend».

## Что сделано
- **ui/ribbon.py** (новый). Собственные иконки `glyph()` (QPainter) и `Ribbon` с 7 вкладками: Файл, Главная, Рисование,
  Редактировать, Просмотр, База данных, Помощь. Реестр `places` хранит для каждого действия одно место (вкладка, группа),
  повторное размещение вызывает `ValueError`. Страницы лежат в горизонтальном QScrollArea, поэтому окно помещается в 1024 px.
- **ui/main_window.py** переписан. Меню и тулбара больше нет. 60 QAction, это 58 действий: «Дисплей» — одна
  QActionGroup из трёх. Вкладка ленты «База данных» показывает блок фильтра и сплиттер «таблица | Предпросмотр/Поля».
  Остальные вкладки показывают редактор. Горячие клавиши и контекстные меню (холст, список элементов, таблица)
  используют те же QAction. Клавиши, которые конфликтуют с вводом текста (Пробел, Enter, Del, Shift+Del), работают только
  в своём виджете. Расположение окна сохраняется автоматически в closeEvent. В строке состояния — координаты курсора в мм.
- **Буфер**: вырезать, копировать, вставить (+20 px), дублировать. **Отменить/Повторить** — история в BackendAPI
  поверх create/update/delete_element; у пересозданных элементов id переназначается.
- **Стиль**: заливка, граница, толщина (QWidgetAction) и «Выровнять ▾» из 6 пунктов. Всё идёт через `le.set_prop/set_props`,
  то есть через ту же панель свойств, одним шагом истории.
- **ui/layout_editor.py**: инструментов, кнопок порядка, side_box и чекбокса рендера больше нет. Список элементов только
  выделяет объект. Линейки в мм. Добавлен тип `ellipse`. Подписи типов берутся из `TYPE_NAMES`.
- **ui/records_table.py**: блок фильтра (поле, условие, И/ИЛИ, значение, «Добавить», выражение, «Сбросить»).
  «Применить» — это `act_filter_apply`, отбор идёт через `query_persons`. Удаление карт — только после подтверждения,
  через `delete_persons`. Кнопок и строки поиска больше нет.
- **ui/main_view.py**:
  - новый `PreviewPanel`: вкладки «Сторона 1 / Сторона 2» (render_card) и таблица «Поле шаблона | Значение из БД»;
  - новый `FieldManager`: дерево «поле → связанные объекты» с иконками стороны и типа, легенда, редактируемое
    значение по умолчанию (`set_field_default`); «Связать/Отвязать» (`link_field/unlink_field`) активны только при выбранном объекте; «Печать» выводит список полей;
  - в `PrintQueueDialog` убраны дублирующие кнопки;
  - `make_icon` удалён.
- **ui/backend_api.py**: тонкие прямые обёртки `query_persons`, `clear_printed`, `delete_persons`, `backup_db`, `vacuum_db`,
  `compact_and_backup`, `restore_from` (закрыть → `restore_db` → открыть), `set_field_default`, `delete_field`,
  `list_field_links`, `link_field`, `unlink_field`. В `ELEMENT_TYPES` добавлен `ellipse`. Механизм PENDING/getattr удалён.
- Удалены `ui/preview.py` (дубль вкладки предпросмотра) и флажок print_mark в форме записи.
- Привязка Backend: «Сохранить как…» → backup_db; «Сжать и восстановить ▾» → compact_and_backup / restore_db;
  «Напечатано» → mark_printed; «Не напечатано» → clear_printed; «В очередь» → set_print_mark;
  «Поиск» → `query_persons` с OR из `contains` по всем полям; «Перейти» — по номеру строки или #ID.
