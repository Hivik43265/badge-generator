# Badge Generator: ручная проверка на Windows 10/11

Для кого: Иван, владелец проекта. Знать программирование не нужно. Время: около 1 часа.
Понадобятся: ПК с Windows 10 или 11, интернет, принтер карт CR80 или обычный принтер, линейка или штангенциркуль.
Отмечайте результат каждого пункта в таблице в конце (раздел 10). Пункты пронумерованы так же, как здесь.

> Обозначения: `C:\BG` — папка, куда скопирован проект (вся папка `badge_generator`). Команды вводятся в **PowerShell**
> (Пуск → «PowerShell»). Каждую строку вставляйте целиком и нажимайте Enter.

## 1. Установка
1.1. Установите Python 3.10 или новее с https://www.python.org/downloads/windows/. В первом окне установщика отметьте **«Add python.exe to PATH»**.
1.2. Проверьте версию:
```powershell
py --version
```
Ожидается `Python 3.10` или выше.
1.3. Создайте окружение и поставьте зависимости:
```powershell
cd C:\BG
py -m venv .venv
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned   # один раз; на вопрос ответьте Y
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```
Ожидается: в начале строки появилось `(.venv)`, установка закончилась без красных ошибок (ставятся Pillow, openpyxl, PyQt6, pytest).
1.4. (Необязательно) Автотесты:
```powershell
python -m pytest -q
```
Ожидается: `137 passed`.

## 2. Запуск программы
2.1. В той же папке, с `(.venv)` в начале строки:
```powershell
python main.py
```
Ожидается: открылось окно «Badge Generator — …project.db», в нём меню «Файл», вкладки «Записи», «Макет» и «Предпросмотр».
2.2. Чтобы начать с чистой базы: «Файл → Открыть БД…» (Ctrl+O) → введите имя `C:\BG\qa_test.db` → «Сохранить». В заголовке окна появится путь к новой базе.
2.3. Чтобы запустить программу в следующий раз: `cd C:\BG`, затем `.\.venv\Scripts\Activate.ps1`, затем `python main.py`.

## 4. Предпросмотр и редактор макета
Перед этим разделом импортируйте файл из п. 3.1 в новую базу.
4.1. Вкладка «Предпросмотр»: выберите запись и сторону «Лицевая», нажмите «Обновить». Ожидается: видна карточка с фото, ФИО и должностью, текст не налезает на другой текст и не выходит за край.
4.2. Переключите сторону на «Оборотная». Ожидается: показывается оборот (или пустой, если на обороте нет элементов).
4.3. Вкладка «Макет»: «Добавить элемент» → тип «field» → поле `last_name`, затем перетащите и растяните мышью. Нажмите «Применить» и вернитесь в «Предпросмотр». Ожидается: элемент стоит там, куда его поставили.
4.4. Сделайте рамку поля маленькой и поставьте длинную фамилию. Ожидается: текст переносится или уменьшается, за рамку не выходит.
4.5. Удалите элемент кнопкой «Удалить элемент». Ожидается: в предпросмотре его больше нет.
4.6. Закройте программу и откройте снова (п. 2.3). Ожидается: записи и макет сохранились.

## 5. Экспорт PNG и PDF
5.1. На вкладке «Записи» отметьте галочкой «Печать» 2 записи. Внизу должно быть «отмечено для печати: 2».
5.2. «Файл → Экспорт…» → формат **PNG** → стороны «Лицевая» и «Оборотная» → записи «Отмеченные для печати» → «Куда»: папка `C:\BG\out_png` → запустить. Ожидается: 4 файла с именами `<id>_front.png` и `<id>_back.png`.
5.3. Проверка PNG: щёлкните файл правой кнопкой → **Свойства → Подробно**, раздел «Изображение». Ожидается: **Ширина 1011, Высота 638 пикселей, Горизонтальное и Вертикальное разрешение 300 точек на дюйм**.
5.4. Экспорт **PDF** → `C:\BG\cards.pdf`. Откройте файл в Edge или Acrobat. Ожидается: 4 страницы (2 записи × 2 стороны). В Acrobat «Файл → Свойства» размер страницы показан как **85,6 × 54 мм** (допуск ±0,15 мм; 3,37 × 2,13 дюйма).
5.5. Распечатайте PDF из Acrobat с параметром **«Фактический размер» (100%)** и измерьте карточку линейкой: 85,6 × 54 мм ±0,15 мм. Запишите фактические размеры.

## 6. Печать на реальный принтер
6.1. Отметьте для печати 2 записи, остальные оставьте без отметки. Запомните, какие отмечены.
6.2. «Файл → Печать…» (Ctrl+P) → откроется окно печати Windows/Qt. Выберите реальный принтер. В «Свойствах» принтера: размер бумаги CR80 или «Пользовательский 85,6×54 мм», **масштаб 100%**, **без «Вписать в страницу»/«Fit to page»**, поля 0 или минимальные.
6.3. Нажмите «Печать», затем в окне «Стороны» выберите «Обе».
6.4. Ожидается: напечатаны **только 2 отмеченные записи**, по 2 стороны, всего 4 листа или карты. Неотмеченные не печатались.
6.5. Измерьте напечатанную карту: ширина ___ мм, высота ___ мм. Запишите **фактическую погрешность** от 85,6×54 мм. Проверьте, что изображение не обрезано и не сдвинуто к краю (поля у разных принтеров разные, запишите как есть).
6.6. **mark_printed (требуется сборка с исправлением D5).** Отметьте N записей и напечатайте их.
- Ожидается: после успешной печати появляется окно «Печать прошла успешно? Снять отметки с N записей?», где N — число напечатанных записей.
- Нажмите «Да». Ожидается: у напечатанных записей снята галочка «Печать», в колонке «Напечатано» стоят дата и время печати, счётчик «отмечено для печати» уменьшился на N.
- Повторите печать и нажмите «Нет». Ожидается: отметки и колонка «Напечатано» не изменились.
- Повторите и нажмите «Отмена» в окне печати. Ожидается: окно про снятие отметок не появляется, ничего не меняется.
6.7. Снимите все отметки («Снять отметки») и нажмите «Печать…». Ожидается: сообщение «Нет записей, отмеченных для печати.»

6.8. **Миграция старой базы.** До обновления программы скопируйте рабочую базу (например, `C:\BG\qa_test.db` с записями из п. 3.1) в `C:\BG\old_backup.db`. Обновите программу и откройте эту базу через «Файл → Открыть БД…». Ожидается: открывается без ошибок, число записей, поля, фото, макет и отметки печати те же, что до обновления, появилась пустая колонка «Напечатано».

## 7. Кириллица в путях и именах файлов
7.1. Создайте папку `C:\Пропуска Тест\Фото` и скопируйте в неё фото из `data_tools\testdata\sets\clean\photos`.
7.2. Скопируйте `reports\qa\win_testdata\Сотрудники_тест.csv` в `C:\Пропуска Тест\`.
7.3. Создайте базу `C:\Пропуска Тест\база.db` (п. 2.2), затем импортируйте `Сотрудники_тест.csv` с папкой фото `C:\Пропуска Тест\Фото`. Ожидается: 5 / 0, фото видны в предпросмотре.
7.4. Экспортируйте PNG в `C:\Пропуска Тест\Экспорт` и PDF в `C:\Пропуска Тест\Карточки.pdf`. Ожидается: файлы созданы и открываются.
7.5. Закройте программу и откройте снова. Ожидается: база `база.db` открылась сама, фото на месте.

## 8. Записи без фото
8.1. «Записи → Добавить»: фамилия «Безфотов», имя «Пётр», фото не указывать, отметить «Отметить для печати» → сохранить.
8.2. В «Предпросмотре» должна быть серая заглушка «нет фото», программа не падает.
8.3. Запустите экспорт или печать этой записи. Ожидается: предупреждение о записях без фото с выбором «продолжить» или «отмена». Если продолжить, карточка сохраняется или печатается с заглушкой.
8.4. Импортируйте `data_tools\testdata\sets\duplicates\persons.csv` (в нём пустой photo_path) без галочки «Требовать фото». Ожидается: строки импортированы, фото показано заглушкой. Затем повторите импорт с галочкой в новой базе. Ожидается: строки без фото пропущены.

## 9. Если что-то пошло не так
Сделайте снимок экрана (Win+Shift+S), скопируйте текст ошибки из PowerShell и запишите номер пункта. Пришлите это BG-Контролёру.
